# Evaluation Outputs

This directory contains LLM-generated translation quality evaluation outputs stored as compressed JSONL files.

## Data Format

Files follow the structure: `{evaluation-schema}/{model-id}/{test-set}/cache.jsonl.gz`

To decompress:
```bash
find outputs/ -name "*.jsonl.gz" -exec gunzip {} \;
```
